# Scalable URL Shortener Service

A lightweight, high-performance URL shortener built with Node.js and Express. Designed with modern system design practices to handle high concurrency using caching and relational database storage.

## Tech Stack
* **Runtime:** Node.js
* **Framework:** Express.js
* **Database:** PostgreSQL (via Prisma ORM)
* **Cache:** Redis
* **Language:** JavaScript (ES6+)

## Current Status: Phase 1 (Express Skeleton)
- [x] Initialized Node.js environment
- [x] Basic Express HTTP server configuration
- [x] Dummy POST endpoint (`/api/shorten`) for initial API validation
- [ ] PostgreSQL Database integration
- [ ] Redis Caching layer
